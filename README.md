# ferranlopezEngDev.github.io

This repository contains the source files for my personal engineering portfolio website, built with MkDocs Material and intended to be published with GitHub Pages.

The site presents a professional engineering profile focused on mechanical engineering, computational engineering, CAD/CAE workflows, simulation, automation, and open-source tools.

## Local development

To run the site locally:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install mkdocs-material
mkdocs serve
```
