# Technical Notes

This section is the planned landing page for future technical notes that support the project work documented in this portfolio.

The intention is to keep notes concise, reusable, and technical. They should function as reference material for modelling decisions, solver behaviour, workflow choices, and validation practice rather than as diary-style posts.

## Planned categories

| Category | Planned scope |
| --- | --- |
| Numerical methods | Nonlinear solvers, root finding, continuation methods, stability, and residual formulation |
| Hydraulics | Hydraulic network equations, head-loss models, boundary conditions, and validation cases |
| CAD/CAE | Geometry preparation, meshing choices, solver inputs, and post-processing workflow notes |
| Structural analysis | Truss and frame fundamentals, local/global axes, and finite element basics |
| Aerodynamics | Small notes that support UAV learning cases and comparison studies |
| Geometry and rotations | Reference frames, robust basis construction, matrices, and quaternions |
| Documentation practices | Units, plotting, reporting structure, and reproducibility habits |
