# Tools

This section lists the main tool families used across the portfolio.

## Core stack

| Area | Tools |
| --- | --- |
| Programming | Python, C++, C# |
| Scientific computing | NumPy, SciPy, pandas, matplotlib, SymPy |
| CAD and geometry | FreeCAD, SolveSpace, OpenSCAD, OpenCascade / OCCT, picoGK |
| Meshing and simulation | Gmsh, Code_Aster, CalculiX, Elmer FEM, OpenFOAM, SU2, SALOME |
| Aerodynamics and analysis | XFOIL, XFLR5, AVL |
| Systems and modeling | OpenModelica, GNU Octave, Scilab |
| Post-processing and visualization | ParaView, Inkscape, Blender |
| Documentation and publishing | LaTeX, Markdown, Git, GitHub, GitHub Pages, MkDocs Material |
