# Projects

This section gathers the main project lines currently documented in the portfolio. Status labels are explicit so that completed context, academic work, active development, learning projects, and planned work are not mixed together.

| Project | Area | Main technologies | Status | Purpose |
| --- | --- | --- | --- | --- |
| HN3Ttk — Hydraulic Network Toolkit | Hydraulic networks, nonlinear solvers, modelling abstractions | Python, C++, NumPy, SciPy, matplotlib | In development | Build a cleaner and more modular hydraulic network toolkit inspired by lessons from an earlier academic prototype |
| UAV CAE Learning Lab | Fixed-wing UAV theory, CAD, FEA, CFD learning workflows | FreeCAD, Gmsh, OpenFOAM, XFOIL, XFLR5, AVL, Python | Early learning phase | Develop step-by-step open-source CAD/CAE studies without presenting an unfinished UAV design as a final product |
| Structural Automation Lab | Structural analysis, local/global axes, preprocessing automation | Python, C++, C#, NumPy, SymPy, Gmsh | Planned / early concept | Build foundations for structural modelling, element transformations, and solver-oriented automation |
| CAD/CAE Open-Source Workflows | Parametric geometry, meshing, simulation workflows, post-processing | FreeCAD, SolveSpace, OpenSCAD, Gmsh, Code_Aster, CalculiX, Elmer FEM, ParaView | Planned / learning phase | Collect small reproducible examples that move from geometry to analysis and interpretation |
| Geometry & Rotations Study | Coordinate systems, rotation handling, robust geometry logic | Python, NumPy, SciPy, SymPy | Learning phase | Develop mathematical foundations that support CAD, simulation preprocessing, and engineering software |
| Computational Engineering Notes | Numerical methods, simulation methods, technical reporting | Markdown, LaTeX, Python, GNU Octave, Scilab | Planned | Build a compact knowledge base that connects theory with engineering computation practice |

Hydranet is not treated as a separate flagship line. It is retained only as legacy academic context within [HN3Ttk — Hydraulic Network Toolkit](hn3ttk.md).
