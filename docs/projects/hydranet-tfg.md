# Hydranet TFG — Legacy Prototype

## Overview

Hydranet was a first academic prototype developed around final degree project work on hydraulic network simulation. It is kept here only as historical context for the later HN3Ttk project line.

## Relationship to HN3Ttk

Hydranet is no longer treated as a separate current flagship project. Its main value today is as an earlier proof of concept that helped define the modelling direction, solver interests, and software architecture lessons now being carried forward into [HN3Ttk — Hydraulic Network Toolkit](hn3ttk.md).

## Technical Areas

- Hydraulic systems
- Numerical methods
- CAD/CAE workflows
- Early engineering software prototyping

## Main Technologies

- Python
- FreeCAD
- NumPy
- pandas

## Current Status

Legacy academic prototype.

Conceptually superseded by HN3Ttk as the current hydraulic network toolkit direction.
