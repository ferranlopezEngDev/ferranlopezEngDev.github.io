# Computational Engineering Notes

## Overview

This section is planned as a compact knowledge base for numerical methods, modelling practice, simulation foundations, and engineering computation.

It is intended to connect theoretical ideas with practical tools used elsewhere in the portfolio, especially when a method needs a short technical note rather than a full project page.

## Purpose

The goal is to build progressively documented notes that are useful in project work: solver references, modelling reminders, validation criteria, plotting habits, and concise explanations of numerical decisions.
