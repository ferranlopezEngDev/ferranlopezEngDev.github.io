# HN3Ttk — Hydraulic Network Toolkit

## Overview

An early-stage hydraulic network toolkit focused on modeling and analyzing piping systems, pressure losses, and flow distribution.

## Technical Areas

- Hydraulic network simulation
- Computational engineering
- Mechanical engineering software

## Main Technologies

- Python
- C++
- OpenModelica
- GNU Octave
